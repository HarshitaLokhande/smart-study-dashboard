📚 Smart Study Dashboard

A simple yet powerful productivity web app built using HTML, CSS, and JavaScript.
It helps users manage tasks, track focus time, and write quick notes — all in one place.

🚀 Live Features

✅ Task Manager

Add new tasks
Mark tasks as complete
Delete tasks
Edit tasks (double click)
Drag & drop to reorder tasks

📊 Progress Tracker

Real-time task completion stats
Visual progress bar
⏱ Pomodoro Timer
25-minute focus timer
Start / Reset functionality
Helps improve productivity

📝 Notes Section

Write quick notes
Auto-save using localStorage
Notes persist after refresh

🌙 Theme Toggle

Light / Dark mode switch

💡 Tech Stack

HTML5
CSS3 (Responsive UI)
JavaScript (DOM + LocalStorage)

📱 Responsive Design

✔ Works on desktop
✔ Works on tablets
✔ Works on mobile devices
